   - Use `git ls-files -co --exclude-standard -z | grep -zEv ...`.

The only way to trap is a deliberate `DEPLOYED_SITE_URL=` override, and a silent wrong host would be worse than a crash. One residual gap: the guard test runs only in Debug. Release gets the same plist, so I did not file this as an issue.
