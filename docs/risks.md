# Risks

Open risks the team knows about, newest at the bottom. Format: date · risk · mitigation · owner · status.

- 2026-10-29 · **No rate limiting on public and creator endpoints.** `POST /api/v1/auth/code` (login codes can be guessed by brute force), `/api/v1/public/*`, the story-tag note form, `POST /uploads` and the model-backed routes (cost) have no per-IP limits in the app. · Configure Vercel Firewall rate-limit rules this week: `/api/v1/auth/code` and `/create/code/session` (e.g. 10 requests / minute / IP), `/api/v1/public/*` and `/t/*` POSTs (30 / minute / IP), model routes `/api/v1/(artworks|products|listings|prompts|transcribe|story)` (20 / minute / IP). Login codes are now random 10-character codes (about 50 bits) and tokens expire after 30 days. · founder (Vercel dashboard) · open
- 2026-10-29 · **Creator auth is dev-mode.** Shared login codes, HMAC bearer tokens with a 30-day expiry and no revocation list; rotating `CREATOR_SESSION_SECRET` signs everyone out. · Acceptable for the hackathon demo with fictional example creators; replace before real artists sign in. · backend · accepted for v0.1
- 2026-10-29 · **Client uploads are public until the server copies them.** Photos are re-encoded in the browser (EXIF and GPS removed) and the public upload is deleted after the private copy is stored; story and thank-you videos stay public by design (unguessable uuid pathnames). · Move client uploads to a private store when presigned private PUTs exist. · backend · open
- 2026-10-29 · **Muse Glimmer runs on the development Mac.** On Vercel the story stage falls back to Muse Spark 1.3 (`provider: "meta-fallback"`). The open-weight stage is only live when the demo runs locally or the Mac is reachable. · Documented in README; the response always says which provider wrote the draft. · team · accepted
- 2026-10-29 · **The sign-in link carries the creator code in its query string** (`/create/code?c=<CODE>`, T070). The code lands in Vercel request logs, browser history, and in any link-preview fetch when the link is pasted into a chat. · Treat the link like a password: hand it over by QR or in person, never post it in a group chat. If it leaks, use New code on `/admin`; the old code and link stop working at once (tokens already issued run to their 30-day expiry). Follow-up: a fragment link (`/create/code#c=<CODE>`, read in the browser) never reaches the server or its logs, but needs JavaScript. · web · accepted for the hackathon
