### Minor
1. **Change it's Back can open a different cut from the art on screen.** `web/components/create/flow.ts:233` (`changeItBack`).
   - What: Back goes to `/create/cutout` whenever `cutoutArtworkId` has a cut, and `cutoutArtworkId` is the last cut shown, not the art on Change it.
   - Scenario: piece → change k1 → Use this (Your cutout on k1) → Back to Before and after → "Back to my original". Change it now shows the piece, but its Back opens k1's cut, whose Back is Before and after.
   - Fix: when the current art (`currentArtworkId`) has a cut, set `cutoutArtworkId` to it before showing Change it (or derive Back from it). Otherwise point at the piece's cut.
2. **A double tap on "Use this area" sends two `cleanup` calls.** `screens/AdjustArea.tsx:71-74` → `flow.ts:85` (`cutArea`). The busy state moved off Adjust the area, and each tap makes a new `pendingArea` nonce. The first result is dropped correctly (nonce check), but both SAM calls run. Fix: ignore a second `cutArea` while `pendingArea` is set for the same artwork, box and candidate.
3. **"Fix the edges" and "Show the cutout" drop focus to `body`.** `screens/YourCutout.tsx:237-238`, `YourCutoutView.tsx:93/102`. The pressed button unmounts as the view switches. Seen: after Fix the edges, `document.activeElement` = `BODY`. Apply already moves focus to the result heading. Fix: on `fixEdges`, focus the first tool (the Add area radio, or the picture group); on `showCut`, focus the `resultRef` heading. This predates T130 (same as the v0.8-rc1 toggle).
4. **The keyboard path cannot add a Remove area mark.**
   - Where: `YourCutoutView.tsx:118-119`. A keyboard or screen-reader user can add an area ("Add the area around your art") and remove marks (the Marks list), but cannot leave a part out.
   - The hint says so honestly, and v0.8-rc1 had no keyboard remove either, so this is not a regression. iOS has whole-art VoiceOver actions.
   - Optional: a "Leave out the centre" / per-quadrant action, or note the gap in `docs/accessibility.md` (T132).
5. **Tapped marks are sent as fractional pixels.** `cutout.ts:39-44` `imagePoint`. For example `{"x":298.008…,"y":237.640…}`. The server accepts numbers, so this is cosmetic; rounding would match the integer boxes.
6. **`docs/api.md` round 2b row 5 puts "Looks good as is" on Your cutout.** In the agreed flow it is on Change it (the report's concern 2). Fix in T132.
