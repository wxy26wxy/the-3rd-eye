## Issues
### Critical — none.
### Important
1. **The edge test does not cover the main source of the terraces** (`sam.ts:114-128` placeRaster still nearest; `mask.ts:351-352`; `test/edge-smoothing.test.ts`). The ramp test feeds 1-working-pixel steps; real terraces come from a SAM raster coarser than its bounds (multi-pixel nearest blocks), and `scaleMask` is a no-op for photos ≤ 2048 px; σ is scaled to the working size, not the raster step. Measured: test case old 4 flat columns / 0.93 px off the line → new 0 / 0.09 (the test does fail on old code); ×4 raster blocks → old 3.5–3.8 px off, new 3.0–3.7 px, flat runs 10/26/58 columns (old 12/28/60). Fix: sample the raster bilinearly in `placeRaster` (grey, threshold 127) or derive σ from the raster step (`bw/rw`); add a test placeRaster(coarse) → finishMask.
2. **Detect drops a tightly framed piece** (`artworks.ts:265`; `sam.ts:37,73,216`). `findCandidates` on the crop still applies `MAX_FRAME_COVERAGE` 0.95 and the 40 % container rule, both designed for whole photos. A painting framed edge to edge → > 95 % → 422 "move or grow the frame" (growing does not help when it fills the photo); a drawing > 40 % with a higher-scoring sub-part is dropped as a container and the part is auto-cut. Tests mock `findCandidates`, so neither path is covered. Fix: `maxCoverage: 1` and a no-container-drop option for detect (new opts field in `lib/ai/types.ts:43`); fixture test with a frame-filling mask.
### Minor
1. A repeat can return an empty description (`artworks.ts:348`, `change/route.ts:33`): the race loser, or an ordinary retry during the winner's describe, gets `alt`/`spoken` = ""; if describe throws, every repeat is 200 with an empty one. Fix: re-describe on repeat when `altText` is null (or 409 `in_progress`); tell clients to fall back to their own copy.
2. An in-flight repeat still runs the model once more before losing at insert; the docs say "no model call" — reword or add a pending marker.
3. A failed detect leaves inconsistent state (`artworks.ts:258-262`): 422 clears `candidates`, sets `lastError`, keeps the old `cleanedUrl`/`ready`; a follow-up `cleanup {candidateIds:[old]}` fails. Keep the old candidates or clear the cut too.
4. Thin strokes thin/fade: σ 0.8 working px before the soft threshold leaves a 1 px line at alpha ≈ 92 (old ≈ 151); corners round by ≈ σ. Acceptable at 2048; note in the ADR.
5. Dark-piece rule (PM fix) is right: `checks.ts:50` `ok = spread ≥ 30 || chroma ≥ 25 || mean ≤ 50`; tests: solid #202020 passes, solid #c8c8c8 and the pencil sketch warn.
6. Deploy order: v0.9 before migration 0006 breaks every creator route; keep as a hard checklist step (applied by the user on 2026-11-02 evening).
7. Lab in JS ok; mock first `POST /products` 201 ok; ×4 total upscale as ruled.
