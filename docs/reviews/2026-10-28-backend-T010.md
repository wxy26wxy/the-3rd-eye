## Important
1. **Client-supplied blob pathnames are read with private credentials and no ownership check** (`imageUrl`, `audioUrl` in artworks, story-video, thank-you, transcribe). One creator could copy another's originals, masks or print files. Fix: enforce `isCreatorPath` on every client-supplied pathname; full URLs must be on the public store host. → fix round 1
2. **`?tag=` on `/media` grants every file under the creator's prefix**, including print files that the API contract says are admin-only. Scope the tag to the order's thank-you media and public kinds. → fix round 1
3. **Token forgery on preview deployments**: a hard-coded dev secret is used unless both NODE_ENV and VERCEL_ENV are production. Fail closed whenever deployed. → fix round 1
4. **No deadline under the 300 s function budget**: 240 s per-call timeout with 2 retries; no request-scoped abort; a kill leaves draft rows and orphan blobs. Lower timeouts, add a request deadline, return a JSON error. → fix round 1
5. **Moderation is advisory**: listings publish even when moderation or the print check failed. Reject with 409. → fix round 1
